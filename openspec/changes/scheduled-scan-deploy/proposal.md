# Proposal

## Why

The map is only ever generated by hand. It should be refreshed twice a week and
published to GitHub Pages without anyone running the scanner
([#2](https://github.com/gjed/roadsurfer-rally-map/issues/2)). The scan would then run
from GitHub's datacenter IPs, which the roadsurfer API may throttle or block. A blocked
scan must fail instead of publishing a half-empty map, and the scan must stay slow
enough not to provoke the block in the first place
([#3](https://github.com/gjed/roadsurfer-rally-map/issues/3)).

## What Changes

- Add jitter to the delay before each request, and wait minutes instead of seconds
  between retries after HTTP 429.
- Count requests, failed requests and HTTP 429 responses, and print a summary line
  with the scan duration.
- Exit non-zero, without writing `--json-out` or `--map`, when more than 10% of the
  requests fail.
- Add `.github/workflows/scan.yml`: a scan twice a week and on manual dispatch with
  `--delay 5`, a Pages artifact with `index.html` and `vendor/`, the scan data as an
  artifact named `offers`, and a deploy job that runs only after a successful scan.
- Document the delay, jitter, backoff, threshold and expected runtime in the README.

Out of scope: scan metadata or a timestamp on the page
([#4](https://github.com/gjed/roadsurfer-rally-map/issues/4)), the release workflow
([#10](https://github.com/gjed/roadsurfer-rally-map/issues/10)), tests and a PR check
([#9](https://github.com/gjed/roadsurfer-rally-map/issues/9)), and a base-URL
override.

## Capabilities

### New Capabilities

- `site-publishing`: the scheduled scan and the GitHub Pages deploy.

### Modified Capabilities

- `rally-scanner`: jittered pacing, minute-scale 429 backoff, and a failed scan when
  too many requests fail.

## Impact

- A full scan with `--delay 5` takes about 70 to 90 minutes on the runner.
- Pages must be enabled once with source "GitHub Actions" before the first deploy.
- Local runs keep the 0.5 s default delay, but a rate-limited request can now stall
  the scan for minutes.
